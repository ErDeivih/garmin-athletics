# Badge

Un estado de una palabra, con punto de color. El texto es lo que informa; el color solo lo refuerza.

## Usa

- `ga-badge--go` para VERDE y «Sincronizado».
- `ga-badge--warn` para AMARILLO y avisos que conviene mirar.
- `ga-badge--stop` para ROJO, errores y «Requiere re-vinculación».
- `ga-badge--info` para información neutra (una novedad, un aviso del sistema).
- `ga-badge--idle` para «Sin datos» o «Pendiente».

## No uses

- Un badge sin texto (solo punto): el color no es accesible por sí solo.
- Badges como botones: si se puede pulsar, es un botón o un chip interactivo con foco.
- Cinco colores en una fila: si todo está resaltado, nada lo está.
